# Aysha's portfolio starter

A lightweight static site built with HTML and CSS. No frameworks, build step, or paid hosting required.

## Local preview
Open `index.html` in your browser. The Blog and other navigation links will work locally.

## Before publishing
- Replace the photo placeholder in `index.html` with an `<img class="portrait" src="assets/your-photo.jpg" alt="Portrait of Aysha Rahman">` and place your photo under `assets/`.
- Replace the generic GitHub and LinkedIn URLs and `YOUR_EMAIL@example.com` in `index.html` with your actual links.
- Review all project, career, and coursework descriptions and update them.
- Replace the example blog post with your own writing.

## GitHub Pages
1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your GitHub username).
2. Upload the *contents* of this folder to the repository root (not the parent folder itself).
3. Open Settings → Pages → Build and deployment; choose Deploy from a branch, `main`, `/ (root)`; Save.
4. Visit `https://YOUR_USERNAME.github.io/` once deployment finishes.

You can edit text and colors at any time without installing dependencies.
